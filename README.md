# testefigma

Landing page responsiva baseada no protótipo do Figma para uma empresa de software sob medida.

## Executar localmente

1. Abra esta pasta no VS Code.
2. No terminal integrado, execute `python -m http.server 8000`.
3. Acesse `http://localhost:8000` no navegador.

O projeto usa apenas HTML e CSS, sem dependências externas ou etapa de build.

## Antes de publicar

- Troque “Nome da empresa” pelo nome escolhido.
- Atualize `contato@seudominio.com` em `index.html` para o e-mail correto.
- Revise os textos dos serviços para refletirem exatamente o que você oferece.
